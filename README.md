# Ntando Mthimkulu | Projects & Performance

A static, responsive portfolio website with the Option I compact header, five main sections, and downloadable case-study evidence.

## Contents

- `index.html` — website entry point
- `styles.css` — responsive Slate & Brass design
- `script.js` — page navigation, project details and interactive career workflow
- `downloads/` — three portfolio case-study workbooks and the Python/SQL pipeline ZIP

## Publish to GitHub Pages

1. Create a GitHub repository (or open your existing portfolio repository).
2. Upload **the contents of this folder** to the repository root. Do not upload only the outer ZIP.
3. Commit the files to the `main` branch.
4. Go to **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Your site will be available at the GitHub Pages URL shown in Settings → Pages after deployment.

## Publish to Render

Create a **Static Site** connected to the GitHub repository. Set **Build Command** to blank and **Publish Directory** to `.` (the repository root). Do not set it to `dist` because this site does not require a build step.

## Important

- The homepage's dashboard is explicitly illustrative. It is not an original screenshot or measured performance chart.
- The portfolio case studies use fictional sample data, not employer results.
- Case study source files are linked on their respective detail pages.
- Contact details and professional statements should be reviewed before public publication.
